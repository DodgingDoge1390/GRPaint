Garrett's GRPaint Version 0.0.2 - 09/14/2026
New Features:
- New UI elements such as New Title and Icon
- Resizable Canvas
- Settings Menu with Help and Resizeable Canvas
- Added Tools, first being Line and Pencil tools
- Added Colors and Width to lines
- Made it to where you can draw on images
- Added AutoSave plus an alert when you don't save the image

- Added support for JPG, JPEG, BMP, and PNG for saving images

- GIFs still move pretty fast

Expected next update:
- AI implementation
- More tools including marker
- Cropping the image
